# 水平标定线角度检测算法全面重构验证报告

## 1. 概述与核心改进

针对 `C:\Users\HYC\Desktop\CameraAjustCalibration` 目录下的相机标定图像（`Mark_1.bmp`, `Mark_2.bmp`, `Mark_3.bmp`，4096×4096 Mono8）在原有算法中返回 `Code 4 (FeatureNotFound)` 的问题，本次对水平标定线角度检测算法（`LineAngleModule::extractLineInfo`）进行了系统性方法论重构：

1. **废弃单一反向 Otsu 假定**：
   - 彻底摆脱“高亮背景下的纯暗线”假设，构建**双极性垂直高通滤波（`boxFilter(1, K)` 局部垂直平滑背景抑制）**；
   - 免疫全图暗角渐晕与背景照明漂移，统一提取暗线、亮线、暗带、亮带、刻槽与瞄准十字线。
2. **水平长程方向形态学聚合**：
   - 采用水平方向线状闭运算（$k_w \times 1$），无损连接断裂刻痕与弱划线。
3. **密集亚像素骨架拟合与残差评估**：
   - 沿水平轴密集提取各连通域骨架质心，通过 `cv::fitLine`（$L_2$/M-估计）精确测定斜率、角度与拟合残差 RMSE。
4. **垂直物理分层聚类与伴随边缘对称中轴合成**：
   - 按垂直位置与夹角对平行线进行物理聚类；
   - 针对宽条带（如 100~200 像素宽的物理标定条），将其成对的上下边界合成对称几何物理中轴：$y_{center} = \frac{1}{2}(y_{top} + y_{bottom})$，避免单边权重失衡引入偏差。
5. **综合显著性打分与主标定线优选**：
   - 结合有效跨度、对比度能量、纵横比与直线度残差，自动锁定画面中最显著的标定工件主轴线。
