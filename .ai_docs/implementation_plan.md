# 实施方案：晶圆圆心与 Notch 检测算法方法论级全面重构

## 一、`EdgeImage_8` 识别失败的深度根因分析（证实存在内外双圆弧）

通过对 `D:\images\谷神星\标准化\8视野圆弧求圆心\EdgeImage_8` 的全景拼接与横向灰度剖面分析，证实该晶圆边缘存在宽约 $1.8 \sim 2.0\text{ mm}$（约 1000~1500 像素）的**去边环带（Edge Exclusion Ring）**，在图像中形成两条平行的同心圆弧：
1. **外圆弧（晶圆真实外边缘 + Notch 所在边界）**：位于车刀纹金属承载台（~65 DN）与去边环（~48.5 DN）交界处，呈深暗谷（~10 DN），物理半径 $R_{\text{outer}} \approx 149.73\text{ mm}$；
2. **内圆弧（去边环与内部晶圆镀膜区交界）**：位于去边环（~48.5 DN）与内部高亮镜面区（~95 DN）交界处，同样呈深暗谷（~10 DN），物理半径 $R_{\text{inner}} \approx 147.80\text{ mm}$。

旧算法在 `EdgeImage_8` 上发生三重连锁崩溃：
- **连锁 1（`sign_x` 镜像误判）**：因晶圆圆心偏西（$X_c \approx +1.75\text{ mm}$），东侧视野（View 0, 1, 4）内圆弧移出画面左边界，左侧全为 50 DN 的去边环，右侧为 70 DN 的反光金属底座。旧算法对比 View 4 左右灰度差（$70 > 50 + 5$），误判相机水平倒装（`sign_x = -1.0`）；
- **连锁 2（全局 `max_val` 抬高阈值漏检外圆弧）**：在西侧视野（View 2, 3, 5, 6, 7）中同时拍到内外双圆弧。旧算法使用整行全局最大值（内侧亮区 $107.9\text{ DN}$）计算粗阈值 `coarse_th = 9.6 + 0.4 * (107.9 - 9.6) = 48.9 DN`，而外圆弧暗谷爬升后的去边环灰度恰好为 **`48.5 DN`（`< 48.9 DN`）**，导致扫描线差 0.4 DN 未触发外圆弧，直接穿透去边环抓到了内圆弧（$R \approx 147.8\text{ mm}$）；
- **连锁 3（跨视野内外圆弧混叠）**：东侧视野抓外圆弧（$149.73\text{ mm}$），西侧视野抓内圆弧（$147.80\text{ mm}$），半径相差近 $2\text{ mm}$，导致圆拟合与滤波彻底失败。

## 二、旧算法在方法论层面的五大本质弊端与重构对策

| 编号 | 旧算法方法论弊端 | 产线失效场景 | 新一代通用算法解决方案 |
|:---:|---|---|---|
| **1** | 用单图左右边缘亮度高低猜测扫描方向与相机镜像 | 当反光底座比晶圆边缘去边环更亮时，方向与坐标系符号全反 | **确定性几何扫描方向**：直接由视野所属采集象限确定由外向内的物理扫描方向 |
| **2** | 用“整行全局最大/最小值”设定单一阈值，且每行只提单点 | 远处亮斑或内圆弧亮区抬高整行阈值，导致外圆弧漏检 | **局部滑动双窗口多候选提取 (`extractRowCandidates`)**：仅考察上升沿前后的局部窗口，支持单行同时提取内外多个候选点 |
| **3** | 假设边缘必为宽阶跃沿 | `EdgeImage_1.5X_8` / `EdgeImage_1.5X` 暗场照明下晶圆内外全黑（~14 DN），边缘仅为 15~25 px 宽的窄脉冲亮线 | **双尺度后方信号窗**：同时评估窄峰窗口 `[xp, xp+35]` 85% 分位数与平台窗口 `[xp+10, xp+100]` 75% 分位数 |
| **4** | 缺乏跨行 2D 连续性聚类与切线斜率物理约束 | `EdgeImage_5X` 内部水平/垂直 IC Die 金属电路网格线干扰及金属底座刀纹噪点 | **2D 连续圆弧链追踪 + 物理斜率强约束**：按切线预测聚类连续链；四角视野强约束 $|dx/dy| \in [0.45, 1.85]$，正交视野强约束 $|dx/dy| \le 0.35$ |
| **5** | 缺乏多视野全局共圆一致性优选与 Notch 连续链过滤 | 双圆弧混叠以及 View 7 Notch 内部孤立微尘导致截面交点跳变 | **多视野全局共圆优选 (`selectBestOuterArcs`) + View 7 深度窗连续链聚类**：按径向由外向内锁定真实外圆周；View 7 在 `[-0.25, +1.35] mm` 深度窗内聚类连续链（长度 $\ge 15$）剔除微尘 |
