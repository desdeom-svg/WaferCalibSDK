### 3. 问题描述 *
- **填报建议**（系统已有部分可直接补全或替换为以下完整版）：
```text
【具体现象】
检测对象为光片晶圆（Bare Wafer），表面无任何 Die、Mark 等局部图案对位特征。原系统方案仅依靠单一 Notch 口局部图像进行灰度模板匹配来确定晶圆位置，存在两大核心缺陷：
1. Notch 只占晶圆外缘极小一部分（弦长占比不足 1%），单一物镜视野无法提供整片晶圆的几何尺寸约束，导致计算出的全局圆心容易产生亚毫米级漂移；
2. 在物镜倍率切换（如 1.5X、2.5X、5X）或照明强弱、对焦微调导致外观灰度变化时，局部模板匹配置信度剧烈波动，造成后续晶圆巡检视野规划失准、不良缺陷坐标映射偏差。

【原因分析】
光片缺少可交叉校验的表面拓扑特征，单个 Notch 模板仅能粗略约束局部旋转角，无法约束全局大圆几何。同时，Notch 的精确旋转角度必须以准确的晶圆圆心为旋转基准，圆心误差直接非线性放大并传递为角度计算误差；跨倍率下边缘倒影、倒角高光与虚焦形态畸变进一步劣化了传统特征匹配的鲁棒性。
```

### 4. 技术方案概述 *
- **填报建议**（重点突出“跨视野空间拓扑+两阶段闭环拟合+Notch多层割线截面中值”三大攻坚突破）：
```text
针对光片无标记且依赖单一Notch模板导致定位漂移的行业痛点，研发并在 WaferCalibSDK 中实现了“跨倍率八视野全局约束与同心割线中值”创新算法方案，核心包含三大技术突破：

1. 【跨视野世界坐标刚体几何变换体系】：
建立运动平台 XY 轴物理坐标与 8 个显微局部视野的亚像素无缝映射模型，将分布在晶圆四象限及四主轴的边缘离散采样点统一投影到全局物理坐标系，以 300mm 大跨距刚体几何彻底消除局部漂移。

2. 【“7+1”两阶段抗缺口干扰外缘闭环拟合】：
- 阶段一：先对 0~6 号无缺口视野进行亚像素边缘梯度提取与弧段优选，采用 Huber 鲁棒加权最小二乘迭代解算出高精度初始晶圆基准圆；
- 阶段二：将基准圆反向投影至第 7 视野（Notch 视野），在径向深度区间 [-0.25, +1.35] mm 内自适应分离 Notch 凹陷点与正常圆弧边缘点，将正常边缘回填组成八视野完整闭环拟合，最大化几何约束刚度。

3. 【Notch 同心多层等深截面交点中值滤波算法】：
彻底摒弃传统灰度模板匹配。以八视野求解得到的极高精度全局圆心为极坐标基准，在 Notch 径向深度 0.3mm~1.0mm 范围内以 0.1mm 步长设置 8 层同心割线截面，求解每层对称角平分线中点，并对所有截面层角度取中位数（Median）。该方法完全免疫晶圆边缘倒角高光、微弱毛刺及跨倍率虚焦形变，实现绝对鲁棒的角度定位。

4. 【工业级工程交付与标准化封装】：
以高效 C++17 与 OpenCV 底座构建，提供简洁稳健的 C ABI / C# P/Invoke 接口（Wafer_FindEightViewEdgeCircle），单次全视野处理耗时稳定在 350ms 以内，支持缺损保护机制。
```
