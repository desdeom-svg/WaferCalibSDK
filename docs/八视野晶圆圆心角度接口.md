# 八视野晶圆圆心与 notch 角度接口

本版仅将四视野计算扩展为八视野，并增加一个角度输出。新增导出 `Wafer_FindEightViewEdgeCircle`，旧 `Wafer_FindFourViewEdgeCircle` 和旧 40 字节结果结构不变，已有调用不受影响。

## C 接口

```c
typedef struct WaferEightViewEdgeCircleResult {
    double center_x_mm;
    double center_y_mm;
    double radius_mm;
    double rms_residual_um;
    double max_residual_um;
    double notch_angle_deg;
} WaferEightViewEdgeCircleResult;

WAFER_API int Wafer_FindEightViewEdgeCircle(
    const unsigned char** image_buffers,
    const double* stage_xy_mm,
    int width,
    int height,
    double pixel_size_um,
    WaferEightViewEdgeCircleResult* result
);
```

仍为六个参数。`image_buffers` 包含恰好八个图像指针；`stage_xy_mm` 包含恰好十六个坐标 `X0,Y0,...,X7,Y7`，单位 mm。不能把八图新接口指向旧版结果结构体。

| 编号 | 采集位置 | 图像黑场方向 |
|---|---|---|
| 0 | +X、+Y 对角 | 右 |
| 1 | +X、−Y 对角 | 右 |
| 2 | −X、+Y 对角 | 左 |
| 3 | −X、−Y 对角 | 左 |
| 4 | +X | 右 |
| 5 | −X | 左 |
| 6 | +Y | 上 |
| 7 | −Y，包含 notch | 下 |

八张图必须同尺寸、紧凑 Mono8，无行填充；宽高均至少 512。文件为 BMP/JPEG/PNG 时，必须先解码，不能直接传入文件压缩字节。调用同步、只读、不保留输入指针；C# 缓冲区必须固定到调用结束。采集 θ 不变，输入实际轴反馈位置。

## 输出与失败行为

- 圆心和半径单位 mm；残差单位 μm。八方向等权计算 RMS，notch 区不参与圆拟合。
- `notch_angle_deg` 为 notch 相对轴坐标 −Y 的偏角，向 +X 为正。
- 返回 0：圆心、半径及残差有效。**角度必须额外检查是否为有限数值**；无 notch 或角度无法可靠提取时，角度为 NaN，仍可成功返回圆心。
- 返回 1：输入非法；4：有效边缘不足；5：圆拟合失败或 RMS 超限；999：内部异常。失败时，非空结果结构的六个 double 全部 NaN。
- 结果结构为顺序排列的六个 double，共 48 字节；C# 使用 Sequential、Pack=8、Cdecl。

角度采用第 7 图缺口轮廓相对拟合圆的径向深度，在 0.3～1.0 mm 的八个截面寻找唯一左右交点，至少三个有效截面时返回中线角度的中位数。跨越过长缺失区的交点不使用。当前方法针对已有约 1 mm 深 notch；更小或严重反光的 notch 可能只返回圆心。

## 坐标与标定限制

仍沿用原映射：

```text
scale = pixel_size_um / 1000
X = stageX + (u - width/2) * scale
Y = stageY - (v - height/2) * scale
```

本版未增加相机转角、倍率参考点偏置、XY 非等比或畸变补偿。当前两组 thick 图的跨倍率圆心偏差仍会存在，不能视为已修复。1.5X 的 3.0 μm/px 和 2.5X 的 1.8 μm/px 为名义倍率换算；残差及输出小数位不代表绝对测量精度。

## C# 调用

完整可运行代码：`samples/EightViewEdgeCircleSample.cs`。

```csharp
[StructLayout(LayoutKind.Sequential, Pack = 8)]
public struct WaferEightViewEdgeCircleResult
{
    public double CenterXmm;
    public double CenterYmm;
    public double RadiusMm;
    public double RmsResidualUm;
    public double MaxResidualUm;
    public double NotchAngleDeg;
}

[DllImport("WaferCalibSDK.dll", ExactSpelling = true,
    CallingConvention = CallingConvention.Cdecl)]
private static extern int Wafer_FindEightViewEdgeCircle(
    [In, MarshalAs(UnmanagedType.LPArray, SizeConst = 8)] IntPtr[] imageBuffers,
    [In, MarshalAs(UnmanagedType.LPArray, SizeConst = 16)] double[] stageXYmm,
    int width, int height, double pixelSizeUm,
    out WaferEightViewEdgeCircleResult result);
```

业务层可使用示例中的包装：

```csharp
// byte[8][] images，double[16] stageXYmm；包装内部固定缓冲区并检查错误码。
var result = WaferEightViewEdgeCircle.Calculate(
    images, stageXYmm, width, height, pixelSizeUm);

bool angleValid = !double.IsNaN(result.NotchAngleDeg)
               && !double.IsInfinity(result.NotchAngleDeg);
```

编译与运行都使用 x64。运行时需要对应的 OpenCV 运行库可被 DLL 搜索路径找到。
