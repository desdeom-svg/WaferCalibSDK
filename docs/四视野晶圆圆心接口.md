# 四视野晶圆外缘圆心：初版

导出：`Wafer_FindFourViewEdgeCircle(const unsigned char** image_buffers, const double* stage_xy_mm, int width, int height, double pixel_size_um, WaferEdgeCircleResult* result)`。

四个图像指针是一个参数；八个坐标是一个参数；结果结构体是一个参数。C#声明及可运行示例见` samples/FourViewEdgeCircleSample.cs `。结构体为五个double，默认8字节对齐，总大小40字节。使用x64进程、Cdecl。

## 输入合同

- 恰好四张相同尺寸紧凑Mono8图像，每张至少width*height字节；宽至少512、高至少256。原生接口无法获知调用者实际数组长度，C#包装负责验证。
- 序号0/1/2/3必须与当前文件编号一致；0/1黑场在右侧、2/3黑场在左侧。轴坐标按X0,Y0,...,X3,Y3排列，单位mm，建议使用曝光时反馈位置。
- θ固定，仅XY移动。相机方向固定、无安装旋转且XY像素当量相等。
- 参考像素是W/2,H/2。统一定位坐标定义：X=Sx+(u-W/2)*pixel_size_um/1000，Y=Sy-(v-H/2)*pixel_size_um/1000。
- 图像、坐标和指针数组仅同步读取，函数返回后不保留。传入文件的解码像素，不是BMP/JPEG文件字节。

## 算法与限制

高斯平滑、逐行粗定位外缘、估计局部背景和内侧信号，以B+0.15*(S-B)定位亚像素交点。基于局部二次曲线和MAD剔除异常点，再将四方向按等权几何最小二乘联合拟合圆。背景噪声过大、饱和、点数或覆盖不足时拒绝。拟合RMS大于10*pixel_size_um时拒绝。

比例0.15是探索阶段的候选值，尚未用独立圆心真值跨材料标定。不得声明达到±1um；在原晶圆上相对旧固定阈值10结果可能有数微米差异。反射率导致的边缘形状改变仍需实物验收。短局部圆弧不能单独用于外推圆心。

## 输出

- center_x_mm / center_y_mm：上述约定下的圆心定位坐标。
- radius_mm：光学边缘拟合半径，未校正倒角/散射的机械外径。
- rms_residual_um：先分别计算每方向的平均径向平方残差，再对四方向等权求平方根。
- max_residual_um：所有有效点最大绝对径向残差。

只在返回0时使用结果。失败时非空result五字段均为NaN；1=输入不合法，4=无法提取足够可靠边缘，5=拟合失败或RMS过大，999=内部异常。残差不是绝对精度，也不是重复性评估。

## 构建与测试

重新运行CMake配置以发现新增源文件，再构建Release的WaferCalibSDK目标。

`python tests/test_four_view_edge_circle.py`：实际DLL合同及已知圆心合成图测试。

`python tests/test_four_view_edge_circle.py --replay`：两组实图经过实际DLL，保存`output/FourViewEdgeCircle/dll_replay.json`，包含输入和DLL的SHA256。

示例.NET Framework编译：`csc /platform:x64 /r:System.Drawing.dll /out:output/FourViewEdgeCircle/FourViewEdgeCircleSample.exe samples/FourViewEdgeCircleSample.cs`。

将OpenCV运行时目录加入当前进程PATH，再运行示例，依次传DLL目录、包含EdgeImage_5X和EdgeImage的根目录、输出CSV路径。示例逐行解码8位BMP，去掉stride填充；不依赖文件扩展名判断格式。

没有更新docs中的旧DLL或工具发布目录；本次构建位于build/Release。
