# 四视野外缘圆心初版实施计划

用户已批准六参数 C ABI：image_buffers、stage_xy_mm、width、height、pixel_size_um、result。

1. 用 Python ctypes 编写实际 DLL 合同测试，先确认现有 DLL 缺少导出。
2. 在现有 C 头文件追加结果结构和接口；独立 C API 源文件实现局部归一化边缘、异常点过滤、四方向均衡几何圆拟合。保持旧 ABI。
3. 构建 Release DLL，测试合成已知圆心、不同亮度/偏置、参数失败、失败输出 NaN、输入不变。
4. 通过 DLL 处理两组真实四图，保存结果及 DLL SHA256；结果不等同于独立绝对精度验收。
5. 提供与实际 ABI 一致的 C# P/Invoke 包装和可运行示例，实际调用两组数据。
6. 独立审查并修复问题，执行相关回归测试；不自动提交或部署到旧工具目录。

固定约定：Mono8 紧凑存储、四图顺序0/1/2/3、θ不变；参考点W/2,H/2；定位坐标X=Sx+(u-W/2)*scale，Y=Sy-(v-H/2)*scale。相机无安装旋转，XY像素当量相等。初版归一化比例0.15来自探索候选，未经独立圆心基准标定，不承诺±1微米。
