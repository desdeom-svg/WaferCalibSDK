# 彩色线扫点阵畸变校正 Sample 设计

## 目标

为 `images/线扫相机畸变矫正/1.bmp` 建立一个独立、可运行的 C++ Sample 与自动化测试，用黄色圆点阵验证并生成彩色 BGR 图像的几何校正结果。

本工作不修改 WaferCalibSDK 的 SDK 头文件、库实现或 C API。

## 已确认的标定数据

- 输入图尺寸：11008 x 2000，BGR 24 bit。
- 相邻黄色圆点中心的物理距离：5 mm。
- 严格排除上下边界被裁断的圆点后，检测到 22 列 x 3 行有效圆点，共 66 个点用于定量拟合。
- 基准仿射拟合下，X 残差 RMS 为 2.19 px、最大绝对值为 4.48 px；残差沿横向具有两端负、中部正的对称非线性趋势。
- 同一拟合下，Y 残差 RMS 为 0.28 px，未观察到可靠的 Y 高阶趋势。
- 标称采样密度：X 为 99.757 px/mm，Y 为 99.889 px/mm；点阵相对像素坐标轴约有 -0.49 度倾斜。

## 建模决策

采用“X 二次非线性 + XY 仿射”模型：

```text
source_x = ax0 + ax1 * u + ax2 * u^2
source_y = ay0 + ay1 * u + ay2 * v
```

其中 `(u, v)` 为校正输出图中的规则点阵坐标。`source_x` 的二次项矫正已经观察到的横向系统性畸变；`source_y` 保留横向倾斜、纵向比例和偏移，不拟合 Y 二次或通用高阶 XY 项。

不选用的方案：

- 仅 Y 校正：会遗留 X 方向最大约 4.48 px 的系统性误差。
- 通用高阶 XY 多项式：当前完整黄色圆点行数有限，Y 高阶项会在图像上下边缘发生不受约束的外推。

## Sample 流程

1. 读取命令行指定的 BGR 输入图；未指定时使用仓库内的 `images/线扫相机畸变矫正/1.bmp`。
2. 转 HSV，以饱和度和亮度约束分割黄色/橙黄色圆点；对连通域按面积、宽高比和圆形度筛选。
3. 将圆心按列聚类、每列按 Y 排序，分配规则 `(column, row)` 点阵索引。
4. 丢弃触及上、下边界，或面积明显低于完整圆点的候选点；只允许完整圆点参与拟合。
5. 使用最小二乘拟合上述映射。规则输出点阵的间距采用 X 平均标称间距，对应 `5 mm`；由此同时完成 Y 的像素纵横比归一化。
6. 为每个输出像素计算输入 BGR 采样坐标，使用 `cv::remap` 生成同尺寸的校正 BGR 图。
7. 输出检测诊断图（有效圆心、行列索引、拟合残差）与校正结果图。

## 文件与命令

- 新增 `samples/sample_line_scan_color_distortion.cpp`：可执行 Sample。
- 新增 `tests/test_line_scan_color_distortion.cpp`：以实际标定图为集成测试输入，验证圆点检测、拟合质量和校正后的几何一致性。
- 在 `CMakeLists.txt` 中仅注册上述 Sample 和测试可执行文件；不链接或修改 SDK 导出接口之外的任何模块。
- 输出目录：`images/线扫相机畸变矫正/`。
  - `output_line_scan_detection.bmp`
  - `output_line_scan_corrected.bmp`

## 验收标准

- Sample 在当前输入图上成功运行，输出两张 BGR 结果图。
- 检测到至少 60 个完整黄色圆点，且至少 20 列、3 行。
- X 二次 + XY 仿射拟合的 X RMS 显著低于纯仿射模型；Y 使用仿射模型即可保持低残差。
- 校正图中有效黄色圆心的列间距和行间距标准差均低于校正前；圆点行相对于输出 X 轴的倾斜明显降低。
- 测试不依赖 SDK C API，且不修改 SDK ABI。
